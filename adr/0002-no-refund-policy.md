# No refund policy for Pine Coin deductions

Status: accepted

Pine Coins are always consumed when an assessment is started, with no refunds under any condition — timer expiry, app crash, network loss, or admin action. This was chosen over partial/full refund scenarios because: (1) it eliminates a class of edge cases around partial refunds, (2) it prevents abuse (users intentionally crashing to reclaim coins), and (3) the per-assessment cost is low enough that the user impact is minimal. The transaction ledger provides full auditability if manual admin intervention is ever needed.
